# Checklist evidence record

Copy this record beneath a checklist item, or into the implementation team's controlled evidence system and link it from the item. Do not put sensitive logs, personal contact details, credentials, or production data in this public repository.

```text
Checklist phase and item:
Accountable owner:
Applicability: APPLICABLE | NOT APPLICABLE
Scope/decision reference and applicability rationale:
Output artifact links and immutable versions:
Related decision IDs and decision-table/test IDs:
Verification command or procedure:
Environment, build and policy versions (where relevant):
Expected result:
Observed result and evidence link:
Open issues, owners and effect on completion/release:
Reviewer and review date:
Required approval record links:
```

An existing file or passing command alone does not establish completion: check the artifact against the item's instructions and record the outcome. An unresolved failure must remain visible. For policy approvals, use the [decision record template](decision-register.md#decision-record-template); this record does not replace required sign-off.
